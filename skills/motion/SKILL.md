# Motion

The animation is code: text, charts, shapes and images placed in an HTML stage and moved on a
timeline. Every word, number and timing stays editable after the fact, and the render is
frame-exact. Nothing is generated by a video model, so there is no synthetic footage and no
synthetic people. Asks that need real footage or photoreal shots are out of scope.

```
templates/motion.html   runtime plus a 16s worked example
scripts/render.py       frame-exact renderer (MP4, ProRes, ProRes 4444 alpha, GIF, PNG stills)
```

## Setup

```sh
python3 -m pip install -r requirements.txt
python3 -m playwright install chromium
```

Run from this folder. ffmpeg comes from the system package manager.

## Workflow

1. Gather the source material and fix the format: 1920x1080 (16:9) by default, 1080x1920
   for vertical social, 1080x1080 square. Aim for 15 to 45 seconds, about 4 seconds per beat.
   Apply the user's brand colors and fonts, from the project's `DESIGN.md` when there is one.
2. Write a beat sheet before any code: one line per scene with its time range, the one thing
   on screen, and how it leaves. Numbers come from the source verbatim, never rounded or
   invented.
3. Copy `templates/motion.html` next to the deliverable and edit only the marked blocks:
   style tokens in `:root`, `FORMAT`, `DATA` (all copy and numbers), `TIMELINE`.
4. Render stills at each beat's settled state and once mid-transition, and look at them:
   ```
   python3 scripts/render.py comp.html --stills 1.5,4.6,9.5 -o stills/
   ```
   Check for clipping, overlap, leftovers from the previous scene, and text too small to
   read on a phone.
5. Render the video. `--scale 0.5` gives a quick draft.
   ```
   python3 scripts/render.py comp.html -o comp.mp4
   ```
6. Hand back the video and the HTML. Opening the HTML in a browser gives a scrubbable
   preview (space plays, arrow keys step a frame, the slider seeks).

## DESIGN.md

Style tokens come from a `DESIGN.md` beside the composition, else at the project root. With
neither, offer styles from the [TypeUI](https://github.com/bergside/typeui) registry and
save the pick beside the composition. No pick keeps the template defaults.

```
r=https://raw.githubusercontent.com/bergside/awesome-design-skills/main/skills
curl -s $r/index.json                      # slugs and names
curl -s $r/<slug>/DESIGN.md -o DESIGN.md
```

Previews: `https://www.typeui.sh/design-skills/<slug>`.

| DESIGN.md | `:root` |
|---|---|
| `colors.surface` (or `neutral`) | `--bg` |
| `colors.text` | `--ink`; `--muted` is `color-mix(in srgb, var(--ink) 60%, var(--bg))` |
| `colors.primary` | `--accent`; `secondary` if primary is near `--ink` |
| `colors.secondary` | `--accent-2`; `success` if secondary took `--accent` |
| `typography.body-md.fontFamily` | `--font`, prepended to the system stack |
| `typography.h1.fontFamily` | `--font-display` |
| `rounded.md` or `rounded.lg` | `--radius` |

Skip its font sizes and spacing; at 1080p, body text is 36px or more and headlines 88 to
120px. Match easing to the tone its prose describes. Load its web fonts with `<link>` or
`@font-face`.

## Timeline API

Times are in seconds. Elements can be passed as an id string or a node.

| Call | Does |
|---|---|
| `place(el, left, top, styles?)` | absolute position in stage pixels |
| `tween(el, start, dur, {x, y, scale, rotate, opacity, blur: [from, to]}, ease?)` | animate transform, opacity, blur |
| `enter(el, at, dur = .7, dy = 40)` | rise and fade in |
| `exit(el, at, dur = .45, dy = -30)` | rise and fade out |
| `countUp(el, start, dur, from, to, fmt)` | ticking number, `fmt(v)` returns the text |
| `track(start, dur, fn, ease?, key?)` | anything else: `fn(p)` gets eased progress 0 to 1 |

Eases: `ease.out` for entrances, `ease.in` for exits, `ease.inOut` for moves, `ease.spring`
and `ease.back` for bars and pops, `ease.linear` for constant motion only.

Before a track starts, only the earliest track for the same element and property applies its
starting state. An element's first `enter` hides it from frame 0, and a later `exit` never
leaks backwards. Seeking backwards gives the same frame as rendering forwards. Give `track`
a `key` when it drives a property so the same rule applies.

CSS `@keyframes` animations also work: each seek pauses every `document.getAnimations()`
entry and sets its time.

## Craft

- One thing moves to be read at a time. Ambient motion such as a soft glow can run underneath.
- Hold every settled state at least 1.2s before it leaves.
- Entrances 0.5 to 0.9s with ease-out; exits 0.3 to 0.5s with ease-in; stagger siblings 0.12 to 0.2s.
- At 1080p, body text at least 36px, headlines 88 to 120px, about 8 words on screen per beat.
- Bars grow from the baseline, values count up once the bar lands, and the bar the story is about gets the second accent color.
- No emoji, clip art, stock icons, grey placeholder bars, film grain or full-frame gradients. No small objects floating in empty space.
- End on the takeaway and hold it at least 2.5s, so the last frame works as a thumbnail.

## Exports

| For | Command |
|---|---|
| Sharing, chat, slides | `-o x.mp4` (H.264, yuv420p, faststart, BT.709) |
| Video editors | `-o x.mov --prores` (ProRes 422 HQ) |
| Overlays | `-o x.mov --alpha` (ProRes 4444, transparent background) |
| Inline previews | `-o x.gif --scale 0.5` |
| Voiceover or music | add `--audio track.mp3` |
| A section only | `--from 4 --to 9` |

## Pitfalls

- `Date.now()`, `setTimeout`, `requestAnimationFrame` and CSS `transition` run on the wall
  clock and break frame-exact rendering. Drive everything from the timeline.
- Load web fonts locally or before `__motion.ready` resolves; the renderer waits on
  `document.fonts.ready`. The default system font stack needs nothing.
- Animate `transform` and `opacity`. Layout properties (`left`, `width`) only through
  `track`, when the layout itself has to change.
- For `--alpha`, the only background should be the one on `#stage`; the renderer clears it.
